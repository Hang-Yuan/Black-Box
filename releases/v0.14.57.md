# Black Box v0.14.57

修正代理模型的上下文窗口自适配，特别覆盖 20K 等小于 Claude Code 原生 auto-compact window 下限的模型。

- 自定义代理别名使用 `CLAUDE_CODE_MAX_CONTEXT_TOKENS` 声明真实窗口，Claude Code 按该容量执行原生自动压缩。
- Claude 家族别名若被代理限制到 100K 以下，Black Box 将容量换算为 Claude Code 支持的 100K 窗口和保守百分比，在声明容量的 80% 前后触发原生压缩。
- 200K 和 1M 等 Claude Code 直接支持的窗口继续按准确 token 数设置。
- 每个 Provider 模型只需保存一次容量，主模型、辅助模型和后续新进程自动跟随。
- Black Box 仍不主动发送 `/compact`；用户手动命令与 Claude Code 原生压缩事件继续正常显示。

该修正确保 `20k`、`200k` 与 `1m` 三类配置均能进入 Claude Code 可执行的原生控制范围。未知容量留空时继续使用 Claude Code 的模型识别和默认值。
