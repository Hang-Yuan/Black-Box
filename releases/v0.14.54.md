# Black Box v0.14.54

- 新会话续接自动进入原对话所在任务组；原对话未分组时，续接也保持未分组。
- 续接对话名自动递增末尾数字：`项目开发` → `项目开发2`，`项目开发2` → `项目开发3`。名称中间的数字保持原样。
- 草稿创建时立即显示名称和分组，发送成为正式会话后继续保留；原对话保持原样。

## Changes

- Fresh-session continuation inherits its source task group. Ungrouped sources create ungrouped continuations.
- Continuation titles increment their trailing number: `Project` → `Project2`, `Project2` → `Project3`. Digits elsewhere in the title remain unchanged.
- The draft shows its name and group immediately and retains them after becoming a durable CLI session. The source conversation is preserved.

## Downloads and signing

macOS Apple Silicon / Intel, Windows x64 (NSIS / MSI), and Linux x64 (AppImage / DEB / RPM) installers are included. `SHA256SUMS` covers the release assets. `latest.json` and updater signatures support macOS, Windows NSIS, and Linux AppImage updates; DEB/RPM installations use their package manager or a manual installer.

Updater packages are signed with the Black Box release key. macOS bundles remain ad-hoc signed and are not Apple-notarized; Windows installers do not carry an Authenticode certificate. Platform trust prompts may still appear.
