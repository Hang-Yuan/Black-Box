# Black Box v0.14.55

长会话续接现在由原会话模型整理有长度预算的任务摘要。先检查目标、已完成事项、未完成事项、待用户决定的问题和证据入口，再创建新会话草稿；发送前仍可编辑。

- 摘要最多 3,000 字符、8,000 UTF-8 字节，原始记录和原会话草稿保留。
- 校验引用与原始记录；生成可取消，原会话有新内容时要求重新生成。格式、长度或引用不合格时最多自动纠正一次，两次生成共用时间上限。
- 新会话继承原任务组、递增名称、API、主模型和子模型。存在待用户决定事项时，先提出问题并等待回复。
- 上下文提示显示当前用量与估计占比，达到较高占用时再提示压缩或续接。

验收：951 项前端测试、400 项原生测试通过；Haiku 和 Sonnet 的隔离真实模型测试覆盖长历史、连续续接、完成状态与证据保留、原记录变动、取消后的迟到结果、分组及模型继承。待决场景均为零执行工具调用、零压缩。模型和工具的基础上下文开销仍然存在；摘要也需由用户检查。

生成摘要需要支持安全模式、独立 fork 和结构化输出的 Claude CLI；能力不足时会提示升级 CLI。更新包使用应用内更新签名，平台代码签名状态与前一版本保持一致。
