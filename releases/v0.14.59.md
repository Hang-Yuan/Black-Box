# Black Box v0.14.59

Claude 型号的上下文窗口改为由 Black Box 按官方能力自动设置。

- Fable 5.x、Opus 5、Sonnet 5、Opus 4.6–4.8 与 Sonnet 4.6 自动使用 1M 上下文。
- Haiku 4.5 使用其官方 200K 上限。
- Claude Code 启动参数与运行栏占用计量读取同一份型号能力表。
- Provider 中遗留的手动容量不会覆盖官方 Claude 型号；官方型号的容量字段只读显示。
- 无法识别的代理模型仍可手动填写实际容量。
