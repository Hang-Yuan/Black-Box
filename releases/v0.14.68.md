# Black Box v0.14.68

修复长任务中 Claude Code 内部 runner 重启后的空白运行态。

- 识别 Claude Code 自动生成的 runner 恢复提示，不把它当成用户新消息。
- 保留原任务、恢复次数与同一会话，不覆盖用户消息的回退锚点。
- runner 重启后只返回 `No response requested.` 时，自动继续未完成任务。
- 前台和后台任务统一进入“重新连接”状态，收到模型事件后恢复正常阶段。
- 自动恢复仍有三次上限，持续失败时明确结束并显示错误。
