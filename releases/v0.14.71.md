# Black Box v0.14.71

## 修复

- 运行中会话增量同步会把前台乐观插入的用户消息与 Claude JSONL 持久化 UUID 对齐，不再显示两份相同消息。
- Black Box 内部空回复续接指令不再作为用户消息展示；存在活跃后台 Agent 时不再向同一轮错误注入续接提示。
- Provider API 错误保留为诊断信息，但不再算作主 Agent 的正式答复。
- JSONL 已记录后台 Agent 结束或失败时，前台运行计数同步结算。

## Validation

- Targeted regression tests cover optimistic-message reconciliation, internal recovery filtering, provider error classification, and active-background recovery gating.
- Full frontend, Rust, TypeScript, production build, candidate audit, app signature, and DMG checksum validation are required before installation.
