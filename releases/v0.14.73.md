# Black Box v0.14.73

## 修复

- 持久登记由 Black Box 启动的 Claude 子进程及其宿主 PID、会话 UUID 和所有权代次。
- 应用异常退出或 macOS 终止路径绕过异步清理时，下一次启动只清理已登记、宿主已消失且命令行身份完全匹配的旧进程。
- 防止同一 Claude 会话产生多个 `--resume` 进程，避免 JSONL 争写、状态闪烁和重复恢复。

## Validation

- Process identity matching requires the exact Claude session plus Black Box stream-json transport flags.
- Startup cleanup ignores unrelated Claude processes and any child whose Black Box owner is still alive.
