# Black Box v0.14.58

完成模型上下文自适配的可见层闭环。

- 运行栏的上下文占用按当前 Provider 模型保存的真实容量计算，切换 20K、200K、1M 模型时同步切换显示窗口。
- 容量留空时继续按 Claude Code 可识别的官方/扩展模型名称使用默认窗口。
- 高占用提示说明 Claude Code 将执行原生自动压缩，不再建议用户手动输入 `/compact`。
- Black Box 不主动发送 `/compact`；模型容量、压缩触发与摘要仍由 Claude Code runtime 管理。

本版本承接 v0.14.57 的小窗口原生参数修正，使底层压缩窗口与界面占用估算使用同一份 Provider 模型配置。
