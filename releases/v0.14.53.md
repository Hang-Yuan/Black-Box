# Black Box v0.14.53

本次更新收尾八项日常使用场景：

- 会话、输入框、侧栏与 Activity 使用执行身份和终态回执；后台工作保持运行状态，迟到终答归回原回复。
- 发送前计算包含缓存 token 的上下文占用，预留响应空间；压缩后续接，显示等待与停滞阶段，失活进程保留会话及输入，长会话可生成续接草稿。
- 打开、切换、拖宽文件面板以及刷新会话时保持阅读锚点。
- 超长代码、SQL 与配置进入独立 Artifact，支持文件目录、换行、逐文件复制和下载。
- 高分辨率图片保留原图，并提供带来源坐标的 1024 像素细节裁图。模型可按需读取相关裁图；具体模型与 CLI 仍可能重编码图片。
- 新增“关于与更新”：Black Box 发布签名校验、下载进度、空闲安装、重启后草稿恢复，以及回滚至已记录的签名版本。签名更新通道从本版开始。
- 历史排程可授权恢复并自动追平当天到期任务；重复轮询复用领取记录，治理待裁单独展示。
- 原生 final 标记保持单向确认；thinking 从聊天状态、导出、搜索等产品投影排除，CLI 原始记录继续用于原生续接。

## Changes

- Execution identities and terminal receipts keep task, composer, sidebar and Activity states aligned, including background work and late final responses.
- Context preflight includes cached tokens and reserves response space. Long tasks expose compaction, continuation and silence stages; missing processes preserve drafts, and long conversations can prepare a handoff draft.
- Reading anchors survive file-panel opening, switching, resizing and conversation reloads.
- Long code, SQL and configuration blocks become Artifacts with a file directory, wrapping, per-file copy and save.
- High-resolution attachments retain their original image and provide coordinate-labelled 1024-pixel detail crops for the model to read. The selected model or CLI may re-encode images.
- About & Update adds signed package verification, download progress, installation when idle, draft recovery after restart and rollback to a recorded signed version. This release starts the signed update channel.
- Authorized historical schedule recovery can automatically catch up today's due task, reuse existing claims and display pending governance decisions separately.
- Native final markers remain confirmed. Thinking is excluded from product chat state, export and search; raw CLI records remain available for native continuation.

## Downloads and signing

macOS Apple Silicon / Intel, Windows x64 (NSIS / MSI), and Linux x64 (AppImage / DEB / RPM) installers are included. `SHA256SUMS` covers the release assets. `latest.json` and updater signatures support macOS, Windows NSIS, and Linux AppImage updates; DEB/RPM installations use their package manager or a manual installer.

Updater packages are signed with the Black Box release key. macOS bundles remain ad-hoc signed and are not Apple-notarized; Windows installers do not carry an Authenticode certificate. Platform trust prompts may still appear.

The v0.15 harness and Memory mainline remain outside this patch.
