# Black Box v0.14.60

Goal 顶栏现在显示 Claude Code 原生 Goal 的真实状态。

- 读取 Claude JSONL 中的 `goal_status` 记录，区分进行中、已完成与已清除。
- compact 或重启应用后，仍可从原始会话恢复当前 Goal。
- Goal 下拉面板显示目标正文，并在完成后显示轮次与 Token 收据。
- Goal 输入长度与 Claude Code 原生 4,000 字符上限保持一致。
