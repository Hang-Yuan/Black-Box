# Black Box v0.14.82

## 新增

- API 配置可读取当前服务商的模型目录，自动选择 Fable、Opus、Sonnet、Haiku 四个家族中可用的最高版本。
- 连接测试会先刷新模型目录；也可点击“自动识别最高模型”单独刷新。

## 行为

- 模型 ID 按服务商接口返回值原样保存。例如 YYLX 返回 `claude-opus-5-5`，Black Box 会直接使用这个路由值，并在界面显示为 Opus 5.5。
- 自动识别后仍可手动编辑。模型目录不可用或缺少某一系列时，现有手动值会保留。
- 官方 Claude 5.x 模型继续自动匹配 1M 上下文，Haiku 4.5 匹配 200K。

## Validation

- YYLX `/v1/models` 实际目录读取与路由 ID 验证通过。
- 自动识别、原值保存、手动值保留、显示名、上下文和连接测试顺序的回归测试通过。
