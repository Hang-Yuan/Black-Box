# Black Box v0.14.56

上下文自动压缩由 Claude Code 统一管理。Claude Code 根据当前模型的上下文容量决定触发时机，Black Box 负责呈现原生压缩事件和保护用户输入。

- 发送用户输入时直接交给 Claude Code，不再先注入 `/compact`。
- 前台与后台任务完成后均不再按 Black Box 自有阈值注入 `/compact`。
- 空终态恢复使用有限次数的原会话续跑，不再自行压缩。
- API 设置可为每个模型保存上下文容量，支持 `20k`、`200k`、`1m` 或准确 token 数；切换模型时自动应用。
- 用户主动执行 `/compact` 的入口、进度状态和结果展示继续可用。
- 兼容升级前已经开始的发送前压缩，完成后仍能恢复原输入。

模型窗口由 Claude Code 的模型识别与当前模型映射共同决定。官方标准模型和明确的扩展模型可留空，由 Claude Code 自动识别；代理商自定义模型名缺少统一的容量元数据时，只需在对应模型旁填写一次，后续启动和切换都由 Black Box 自动传给 Claude Code。
